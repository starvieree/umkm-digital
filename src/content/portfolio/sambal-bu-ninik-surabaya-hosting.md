### Profil Klien & Masalah
**Sambal Bu Ninik** (Surabaya) memproduksi sambal botol kaca khas Jawa Timur (Sambal Bawang, Cumi Asin, Klotok) berizin P-IRT dan Halal. Website katalog produk sebelumnya di-hosting di paket shared hosting murah yang kerap mengalami *down* atau error saat jam sibuk promosi. Waktu pemuatan halaman mencapai 6,8 detik di koneksi seluler smartphone, dengan skor Google PageSpeed merah di angka 42. Akibatnya, calon pembeli sering kali membatalkan pesanan sebelum gambar sambal sempat terbuka sempurna.

### Apa yang Dikerjakan
- Melakukan audit teknis menyeluruh terhadap performa website dan metrik Core Web Vitals (LCP, FID/INP, CLS).
- Memigrasikan website dan basis data ke cloud hosting modern berkecepatan tinggi dengan jaminan uptime 99.9% tanpa gangguan (*zero downtime*).
- Mengonversi dan mengompresi ratusan foto produk resolusi tinggi ke format modern WebP ringan tanpa mengurangi kejernihan visual.
- Mengatur caching tingkat server (*server-level caching*), CDN regional Indonesia, dan memangkas file JavaScript & CSS yang memperlambat render.
- Memasang sertifikat SSL/HTTPS Grade A+ dan mengonfigurasi pencadangan data otomatis (*daily automated backup*).

### Bagaimana Pengerjaannya
- **Migrasi Tanpa Henti (Zero Downtime)**: Pemindahan file dan database dilakukan melalui staging server terlebih dahulu, memastikan transaksi WhatsApp pemesanan tetap berjalan lancar tanpa terputus.
- **Pembersihan Aset Berat**: Mengganti plugin berat dengan script modular ringan serta menunda pemuatan aset non-kritis (*defer non-critical JS/CSS*).
- **Optimasi Mobile Core Web Vitals**: Memperbaiki Largest Contentful Paint (LCP) dari 5,4 detik menjadi 1,1 detik, dan meniadakan pergeseran tata letak kumulatif (*CLS = 0*) saat halaman dibuka di layar ponsel.

### Hasil yang Didapat
- Skor Google PageSpeed melonjak drastis dari 42 menjadi 98 di perangkat seluler (mobile) dan 100 di desktop.
- Waktu pemuatan website terpangkas dari 6,8 detik menjadi hanya 0,9 detik, bahkan lancar dibuka dengan koneksi 4G standar.
- Tingkat pentalan (*bounce rate*) pengunjung turun sebesar 62%, mendorong kenaikan konversi klik tombol pesanan WhatsApp hingga 2,8 kali lipat.
